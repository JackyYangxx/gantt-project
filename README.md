# Gantt Project

协同甘特图项目管理工具，适用于小团队。本地运行，支持局域网内多人实时协作。

## 使用流程

### 1. 安装与启动

```bash
npm install
npm run dev
```

服务端运行在 `http://localhost:3001`，客户端开发服务器在 `http://localhost:5173`。  
团队成员可通过 `http://<你的IP>:3001` 访问。

### 2. 注册第一个账号

打开页面后先注册。**第一个注册的用户自动成为管理员**，拥有管理后台的访问权限。

### 3. 创建项目

登录后在项目列表页点击 **创建项目**，输入项目名称即可。  
只有被添加到项目中的用户才能查看和编辑。

### 4. 添加用户（管理员）

管理员通过 `/a7x9k2m` 进入管理后台：
- **创建账号** — 为新成员创建账号并分配项目权限
- **修改密码** — 重置任意用户的密码
- **查看所有用户列表**

### 5. 管理任务

在项目甘特图页面：
- **创建任务** — 点击侧栏「+」按钮，填写任务名称、日期范围、进度
- **依赖关系** — 在任务表单的「Dependencies」下拉勾选前置任务
- **调整日期** — 在甘特图上拖拽任务条
- **批量导入** — 通过 Excel 文件导入任务（甘特图顶栏提供模板下载）

### 6. 查看甘特图

- 点击任务名称查看详情弹窗
- 顶部按钮切换 **日 / 周 / 月** 视图
- 拖拽甘特图背景区域平移视图
- 任务条颜色可在创建/编辑时通过 Color 选择器自定义
- 进度 >= 100% 自动显示绿色

### 7. 桌面应用（Electron）

Windows x64 用户可直接下载安装包（从 GitHub Releases 页面获取），无需配置 Node.js 环境。

## 数据迁移

### 开发模式

数据库文件位于 `server/data/gantt.db`，复制该文件即可迁移到其他设备。

### EXE 桌面应用（Windows）

数据库及配置文件存储在以下位置：

```
%APPDATA%/gantt-project/
├── config.json          # JWT 密钥（会话令牌）
└── data/
    └── gantt.db         # 项目数据
```

迁移步骤：

1. 在原电脑上关闭 Gantt Project 应用
2. 复制 `%APPDATA%/gantt-project/` 整个文件夹
3. 在新电脑上安装并运行一次 Gantt Project（会自动创建目录结构）
4. 关闭新电脑上的应用，将备份的文件夹覆盖到同路径
5. 重新打开应用即可

> 如果只迁移 `gantt.db` 而不复制 `config.json`，之前登录的会话令牌会失效，需要重新登录。

## 技术栈

- **前端** — React + Vite
- **后端** — Fastify
- **数据库** — SQLite + better-sqlite3（WAL 模式）
- **甘特图** — Frappe Gantt
- **实时协作** — Yjs + y-websocket（CRDT 协议）
- **桌面端** — Electron + electron-builder（Windows x64）

## 功能

### 项目管理
- 用户注册和登录
- 多项目管理，支持创建、重命名、删除
- 项目权限控制 — 只有被授权的用户才能查看和编辑项目

### 任务管理
- 任务 CRUD，支持层级结构（父子任务）
- 任务进度百分比滑块 + 进展详情备注
- 任务依赖关系
- Excel 导入导出（.xlsx）
- 提供导入模板下载

### 甘特图
- 拖拽调整任务日期
- 日/周/月视图切换
- 任务自定义颜色

### 实时协作
- CRDT 驱动的多人实时同步
- 在线用户感知（显示谁在线）
- WebSocket 数据持久化到 SQLite

### 管理后台
- 管理员账号管理（路径：`/a7x9k2m`）
- 创建账号时可分配项目权限
- 修改用户密码

## 脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动开发模式（服务端 + 客户端） |
| `npm run dev:electron` | 启动 Electron 桌面开发模式 |
| `npm run build:client` | 构建客户端生产版本 |
| `npm run build:electron` | 构建 Electron 桌面应用 |
| `npm run test:e2e` | 运行 E2E 测试（Playwright） |
| `npm run reset-db` | 重置数据库 |
